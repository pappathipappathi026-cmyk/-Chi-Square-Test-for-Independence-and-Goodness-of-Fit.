# Chi-Square Test for Independence and Goodness of Fit

## Project Description

This project demonstrates the application of the **Chi-Square Statistical Test** using Python. The Chi-Square test is a non-parametric statistical method used to analyze categorical data and determine whether there is a significant difference between observed and expected frequencies.

The project covers two important types of Chi-Square tests:

### 1. Chi-Square Test for Independence
This test is used to identify whether two categorical variables are associated or independent of each other.

**Example:** Analyzing the relationship between people's occupations and their residential neighbourhoods.

The project uses Python libraries such as NumPy and SciPy to calculate:
- Chi-Square Statistic
- Expected Frequencies
- P-value
- Degrees of Freedom

The result shows a significant association between occupation and neighbourhood (p-value = 0.0004).

### 2. Chi-Square Goodness of Fit Test
This test determines whether observed data follows an expected distribution.

**Example:** Analyzing the number of customers visiting a shop from Monday to Friday to check whether customer visits are equally distributed.

The calculated p-value is 0.3595, indicating that there is insufficient evidence to reject the assumption of equal daily customer visits.
